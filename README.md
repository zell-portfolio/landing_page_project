# ☕ Ngopi Yuk! — Digital Marketing Landing Page

**Ngopi Yuk!** is a coffee shop landing page project developed as part of a Digital Marketing bootcamp. This page is designed to introduce the product, highlight business advantages, build trust with potential customers, and drive visitors to contact the business via WhatsApp.

This project also serves as an exercise in bridging digital marketing requirements with simple web development. The landing page can be further developed to support SEO strategies or used as a destination page for digital advertising campaigns.

---

## 🎯 Project Objectives

- Create a promotional landing page for a coffee shop business.
- Present product information, unique selling points (USPs), testimonials, and contact details clearly.
- Provide a clear Call to Action (CTA) to encourage visitors to contact the business via WhatsApp.
- Understand how content structure and User Experience (UX) support digital marketing efforts.
- Establish a foundational web page that can be further optimized for SEO and ad campaigns.

---

## ✨ Features

- **Hero Section** with a compelling promotional message and primary CTA.
- **Value Proposition Section** highlighting the coffee shop's advantages.
- **Menu List** with clear pricing.
- **Customer Testimonials** to build social proof.
- **Interactive FAQ** to address potential customer objections.
- **Floating WhatsApp Button** for immediate business contact.
- **Scroll-triggered Animations** for enhanced user engagement.
- **Fully Responsive Design** optimized for both mobile and desktop devices.
- **Single-Page Navigation** for a seamless user journey.

---

## 🛠️ Tech Stack

- **HTML5** for semantic page structure and content.
- **CSS3** for styling, layout (Grid/Flexbox), animations, and responsiveness.
- **Vanilla JavaScript** for interactions (e.g., FAQ accordion, scroll reveal).
- **Google Fonts** for consistent and modern typography.
- **WhatsApp Click-to-Chat** as the primary conversion channel.

> **Architecture Note**: All HTML, CSS, and JavaScript code is contained within a single file (`index.html`). This project does not use a backend, database, or build tools to maintain simplicity and maximize page load speed.
